# 카와이 증권 API 연동 안내서

## 1. 먼저 알아둘 점

이 프로그램은 키움 OpenAPI+와 키움 REST API를 지원합니다. 연결 표시가 녹색이어도
실거래 주문은 자동으로 허용되지 않습니다. 계좌, 종목, 주문 수량, 운용 한도, 정규장
신호와 현재 실행의 실거래 승인을 모두 확인한 뒤에만 주문 경로가 열립니다.

AppKey, SecretKey, 계좌 비밀번호, 접근토큰은 소스 코드와 SQLite에 저장하지 않습니다.
키 파일은 프로그램이 실행 중일 때만 읽고 원문을 화면이나 로그에 출력하지 않습니다.

## 2. 키움 REST API 연결

1. [키움 REST API 계좌·IP 등록](https://openapi.kiwoom.com/mgmt/VOpenApiRegView?dummyVal=0)에서 사용할 계좌와 현재 공인 IP를 등록합니다.
2. AppKey와 AppSecret을 발급받아 각각 별도 텍스트 파일로 보관합니다.
3. 프로그램에서 `REST API 연결`을 누릅니다.
4. 실전투자 또는 모의투자 서버를 선택하고 두 키 파일을 지정합니다.
5. 연결 후 계좌번호, 예수금, 주문가능금액과 현재가가 정상 조회되는지 확인합니다.
6. 다른 PC나 다른 인터넷 회선을 사용하면 공인 IP가 바뀌므로 등록 페이지에서 새 IP를 먼저 추가합니다.

프로그램은 접근토큰 `au10001`, 계좌 확인 `ka00001`, 현재가 `ka10001`, 계좌 잔고
`kt00018`, 예수금 `kt00001`, 실시간 체결 `0B`를 순서대로 확인합니다. 주문은 매수
`kt10000`, 매도 `kt10001`, 정정 `kt10002`, 취소 `kt10003`을 사용합니다.

## 3. 키움 OpenAPI+ 연결

1. 키움 홈페이지에서 OpenAPI+ 서비스 사용 등록을 마칩니다.
2. Windows용 키움 OpenAPI+ 모듈을 설치합니다.
3. 32비트 프로그램 EXE를 실행하고 `OpenAPI+ 로그인`을 누릅니다.
4. 키움이 띄운 공식 로그인 창에서 로그인합니다. 홈페이지 로그인 상태만으로 ActiveX API가 연결되지는 않습니다.
5. 계좌번호가 로딩되면 4~8자리 계좌 비밀번호를 입력하고 `비밀번호 세팅`으로 조회를 확인합니다.

OpenAPI+ 로그인 창은 키움 ActiveX가 직접 표시합니다. 보이지 않으면 화면 배율을
확인하고 작업표시줄 뒤에 숨은 로그인 창이 있는지 확인합니다.

## 4. 중간가 주문

신규 매수·매도와 정정 주문은 10단계 호가에서 매도1호가와 매수1호가를 읽습니다.
두 가격의 산술 중간값을 계산한 뒤 한국거래소 호가단위에 맞춰 매수는 아래쪽,
매도는 위쪽 유효 호가로 보정하여 지정가 주문을 보냅니다. 호가가 없거나 서로
뒤집힌 경우에는 주문을 보내지 않습니다.

취소는 `호가·미체결·위험관리` 탭에서 미체결 주문을 선택한 뒤 원주문번호로
요청합니다. 정정도 선택한 원주문번호와 현재 중간가를 사용합니다.

## 5. 실거래 안전 순서

1. 처음에는 모의투자로 현재가, 잔고, 주문·정정·취소를 확인합니다.
2. 주문 수량과 종목별 운용 한도를 작게 설정합니다.
3. 일일 최대 손실률을 설정합니다.
4. 실전에서는 현재 실행에 한해 `실거래 자동주문 승인`을 켭니다.
5. `자동 운용 시작` 후 자동매매 ON, 전송 상태 양호, 정규장 신호를 확인합니다.
6. 이상이 있으면 `Ctrl+Shift+Q` 또는 `긴급 정지`를 사용합니다.

긴급 정지는 자동운용을 먼저 멈춥니다. 미체결 전체 취소와 보유 전 종목 시장가
청산은 별도 최종 확인을 통과한 경우에만 실행합니다. 이 긴급 청산만 예외적으로
시장가를 사용합니다.

## 6. KB증권 연동

KB증권 핀테크스토어는 가입 신청, 관리자 승인, 제휴 검토, 앱 등록과 별도
자격증명이 필요한 파트너용 API입니다. 일반 키움 키를 KB에 재사용할 수 없습니다.
프로그램의 `KB 제휴 API 안내`에서 공식 페이지를 열 수 있으며, 실제 KB 주문 연동은
KB증권이 승인한 API 명세와 테스트 자격증명을 받은 뒤 별도 어댑터로 추가해야 합니다.

- [KB증권 제휴 안내](https://store.kbsec.com/aboutpartner)
